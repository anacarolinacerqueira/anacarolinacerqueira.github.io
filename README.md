# anacarolinacerqueira.github.io

Site pessoal de Ana Carolina Cerqueira (Analista de Testes / Qualidade de Software).

Site estático em HTML, CSS e JavaScript, sem build. Estrutura:

- `index.html`: conteúdo da página
- `css/styles.css`: estilos
- `js/reveal.js`: animação de revelar os elementos ao rolar a página
- `img/`: imagens

A versão anterior do site está preservada no branch `backup-site-antigo`.
